# Sol协作Luna

本技能用于组织主任务，Luna独立任务和中间产物任务。所有面向用户的任务说明，任务标题，清单标题和阶段标题都使用简洁中文，ResNet50，YOLOv5，DETR，Luna，sol和threadId等名称按原样保留。

## 主任务职责

1. 由sol负责总体计划，安全边界，任务调度，结果审核，整合和最终交付。
2. sol必须保存每个独立任务的threadId，并在整合前读取该任务反馈。
3. sol必须记录创建来源，创建时间，任务目标，允许文件，禁止事项，验证命令，验收标准和交付内容。

## 项目目录检查

创建任何新对话前，先调用项目列表能力并确认目标项目。

1. 优先选择当前主任务对应的项目，核对项目名称，项目路径和isGitRepository状态。
2. 创建项目任务时，必须传入该项目的projectId，并将任务类型设置为project。
3. Git项目默认使用worktree环境，非Git项目使用local环境，用户明确要求直接使用已保存项目时使用local环境。
4. 禁止把项目工作创建为projectless任务，禁止省略projectId，禁止在无法确认项目时自行创建无项目对话。
5. 如果项目列表中没有匹配项目，主任务必须先报告缺少项目目标并等待处理，主AI不能退回无项目模式创建任务。

## Luna任务委派

1. 新工作必须创建为独立Codex任务，并使用Luna模型。
2. 委派提示必须使用中文，必须写明任务目标，输入范围，允许文件，禁止事项，验证命令和交付内容。
3. 委派提示必须明确任务来源为AI创建，不能把AI创建任务伪装成用户创建。
4. Luna任务完成后，sol必须读取反馈，检查实际文件差异和测试结果，再决定是否整合。

## 中文标题规则

任务标题使用以下顺序，AI创建tag，任务类型，主题，日期tag，数字tag。日期tag和数字tag必须位于末尾。前面已经出现AI创建tag时，后续任务类型和主题不得再次出现AI。

标题示例为，AI创建，部署任务，ResNet50模型部署，20260803，01。

标题中的普通说明和格式化标题必须使用中文。代码，模型名，路径，版本号，数字和缩写保持原样。密码，密钥和其他敏感信息不得进入标题，任务提示，日志摘要，截图或公开中间产物。

## 并行和部署顺序

1. 主任务，独立Luna任务和任务内部派生代理都计入总并行度。
2. 总并行度最多为5，达到5后禁止创建新任务，也禁止通过失败重试绕过限制。
3. 只有文件范围完全不重叠，依赖关系互不阻塞的任务才能并行。
4. 同一模型的部署顺序固定为ResNet50，YOLOv5，DETR，前一模型未完成验收时不得启动后一模型。

## 审核和整合

Luna报告完成后，sol必须依次审核实际差异，文件范围，验证命令输出，运行日志，安全边界和验收标准。审核通过后才能整合交付。审核未通过时必须保留任务状态和证据，不能直接归档或宣称完成。

## 中间产物生命周期

中间产物任务用于向用户索取资料或展示独立清单。中间产物任务在工作完成后仍必须保持可见。

1. 用户明确确认可以归档时，才允许归档中间产物任务。
2. 用户主动执行归档操作时，才允许归档中间产物任务。
3. 代理完成，主AI读取反馈，审核通过，主AI完成整合，都不能单独触发中间产物任务归档。
4. 用户可以在主任务或对应中间产物任务中回复，主AI必须通过threadId读取并汇总信息。
5. 未获得用户确认或用户主动归档前，禁止自动归档，自动删除，自动清理或隐藏中间产物任务。

## 完成交付检查

交付前必须报告已审核的实际差异，验证结果，整合状态，任务来源，项目目录，threadId和中间产物可见状态。只有在项目目标正确，中文标题正确，验证完成，整合完成且归档条件满足时，主AI才能声称任务完成。
